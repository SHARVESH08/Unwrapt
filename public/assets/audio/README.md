# Default audio library

Drop royalty-free tracks here to power the bundled default audio. A gift that
references `"default:<name>"` (see `src/config/defaultAudio.ts`) plays the
matching file below. If a file is missing, that track simply stays **silent** —
the player never breaks.

| Reference            | Expected file                  | Role                        |
| -------------------- | ------------------------------ | --------------------------- |
| `default:soft-loop`  | `default-soft-loop.mp3`        | Background loop (chapters)  |
| `default:warm-ending`| `default-warm-ending.mp3`      | Normal finale ending        |
| `default:love-ending`| `default-love-ending.mp3`      | Proposal (special) ending   |

> No personal/keepsake audio is included. Source tracks from a royalty-free
> library (e.g. Pixabay Music, Free Music Archive) and place them here.

The special ending track is held at exactly **28s** until the receiver taps the
finale photo, then resumes — so pick/trim a special track where ~28s is a
natural pause.

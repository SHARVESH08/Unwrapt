# Landing assets

Drop the "how it works" demo here for the landing page hero:

| File                              | Used for                                  |
| --------------------------------- | ----------------------------------------- |
| `how-it-works.mp4`                | The demo video (plays on click).          |
| `how-it-works-poster.jpg`         | The still shown before play (optional).   |

Both are optional. If the poster is missing, an aurora wash is shown instead;
if the video is missing, the play button still appears (it just won't load a
file until you add one). Recommended video: 16:9, ~1–2 min, H.264 MP4.
